# Glossary

## Terms

- Audit trail: A durable record of what happened, when it happened, and which inputs, prompts, models, and costs were involved.
- Bronze table: A raw or lightly processed table that preserves source-level detail.
- Gold table: A curated table intended for reporting, operations, or downstream use.
- Dead letter: A location for records that failed processing and need later review.
- Pipeline run ID: The unique runtime identifier passed through a pipeline execution.
- Prompt hash: A stable hash of the prompt text used for a model call.
- Input record hash: A stable hash of the original input record.
- Quality gate: A validation step that blocks bad data before expensive or risky processing.
- Data contract: A documented expectation for fields, types, allowed values, and ownership.
